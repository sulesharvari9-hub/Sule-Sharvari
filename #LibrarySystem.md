# 
 Library Management System (Java - Console Based)

##  Description
This project is a console-based Library Management System developed using Java. It allows users to manage books efficiently by adding new books, viewing available books, issuing books, and returning them. The system uses a menu-driven interface and demonstrates basic Object-Oriented Programming concepts.

## Features
- Add new books to the library  
- View all available books  
- Issue books to users  
- Return issued books  
- Display book status (Available / Issued)  
- Simple and user-friendly menu system  

##  Technologies Used
- Java  
- OOP Concepts (Classes & Objects)  
- ArrayList (for data storage)  
- Scanner (for user input)  

##  How to Run
1. Compile the program:
   javac LibrarySystem.java

2. Run the program:
   java LibrarySystem

## Learning Outcomes
- Understanding of Object-Oriented Programming (OOP)  
- Implementation of classes and objects  
- Handling collections using ArrayList  
- Working with loops and conditional statements  
- Building real-world console applications  

## Note
This project is designed to run in terminal environments such as GitHub Codespaces. It does not require any graphical interface.
