#  Result Management System (Java - Console)

## Description
A Java-based console application to manage student results. It allows adding student details, calculating total and percentage, and displaying pass/fail status.

## Features
- Add student details
- Calculate total and percentage
- Display results
- Search by roll number

## Technologies Used
- Java
- OOP Concepts
- ArrayList

## How to Run
javac ResultSystem.java
java ResultSystem
