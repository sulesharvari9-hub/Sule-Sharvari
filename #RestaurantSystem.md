# 🍽️ Restaurant Management System (Java - Console Based)

## 📌 Description
This project is a console-based Restaurant Management System developed using Java. It allows users to view a menu, select food items, enter quantity, and generate a final bill. The system is designed to run in a terminal environment, making it suitable for platforms like GitHub Codespaces.

## 🚀 Features
- Display restaurant menu with prices  
- Take multiple food orders  
- Calculate total bill automatically  
- Simple and user-friendly interface  
- Runs completely in terminal (no GUI required)  

## 🛠️ Technologies Used
- Java  
- OOP Concepts  
- Scanner Class for user input  

## ▶️ How to Run
1. Compile the program:
   javac RestaurantSystem.java

2. Run the program:
   java RestaurantSystem

## 🎯 Learning Outcomes
- Understanding of basic Java programming  
- Implementation of loops and conditional statements  
- Handling user input using Scanner  
- Real-world problem simulation using console application  

## 💡 Note
This project is designed for environments without graphical support (like GitHub Codespaces), so it uses a console-based interface instead of GUI.
